# DUST OS
An operating system designed for heavy multitasking, gaming, and the diverse needs of various users.
It is intended for everyday use by a broad audience—much like Windows—and its driver support is being 
developed to closely mirror the Windows ecosystem.

Dust-OS is a direct descendant of Unix, one of the premier operating systems of the 1970s that spawned numerous 
derivatives—often referred to as "Unix-like" systems—each with its own unique development path. Dust-OS was built
using the original Unix source code, which was comprehensively overhauled to modernize the system while maintaining 
its Unix lineage.

Dust-OS utilizes a hybrid kernel designed to prioritize performance and driver compatibility; the specific hybrid
kernel used here is named [Aethel hybrid kernel](system/aethel).
